Write2Audiobook is a powerful tool that converts text files into audio files from a command-line interface (CLI). This tool aims to make reading more accessible to people with visual impairments and for those who prefer the audio format.

Use this tool to convert the following document types into audio files:

* Ebooks
* Plain text files
* PDF files
* Microsoft PowerPoint presentations
* Microsoft Word documents

To learn how to use Write2Audiobook, see the [Quick start guide][1]. For more detailed reference information, see the [User guide][2].
